# Estruturas de Dados e Ordenação

Programa em Python com menu interativo no terminal que implementa:

- Pilha (LIFO)
- Fila (FIFO)
- Fila circular
- Algoritmos de ordenação: Bubble Sort, Selection Sort e Insertion Sort

## Como executar

Requer Python 3 instalado. Na pasta do projeto, execute:

```
python menu.py
```

## Como usar

No menu principal, digite o número da opção desejada:

1. Pilha
2. Fila
3. Fila circular
4. Ordenar
5. Sair

Em pilha, fila e fila circular, crie primeiro a estrutura (opção 1) informando o tamanho máximo. Depois é possível armazenar valores, extrair valores e imprimir o conteúdo.

Em ordenar, escolha o algoritmo, informe quantos números deseja ordenar e digite cada um deles.

## Estrutura do projeto

| Arquivo            | Descrição                                            |

| `menu.py`          | Menu principal do programa                           |

| `fila.py`          | Implementação da fila                                |
| `fila_circular.py` | Implementação da fila circular                       |
| `ordenar.py`       | Algoritmos de ordenação                              |
